Netflix Data Analysis — Capstone Project

Exploratory Data Analysis Using Python

An exploratory data analysis project focused on understanding Netflix's movie and TV show catalog through data cleaning, analysis, and visualization.

Project Overview

This capstone project explores a Netflix titles dataset using Python and its data analysis libraries.

The goal is to transform raw dataset information into meaningful insights through data exploration, comparisons, and visualizations.

The project covers different aspects of Netflix's catalog, including content ratings, movie durations, content types, release years, and country-wise production.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Project Workflow

1. Data Exploration

- Load the Netflix dataset.
- Examine the dataset's structure and columns.
- Understand the distribution of movies and TV shows.
- Inspect data types and identify potential data-quality issues.

2. Data Cleaning and Preparation

- Inspect missing values.
- Identify data-quality issues.
- Prepare the dataset for analysis.
- Organize the relevant information for visualization.

3. Exploratory Data Analysis

Explore the dataset to understand patterns and differences across several dimensions.

4. Data Visualization

Create visualizations to communicate the findings clearly.

How to Run the Project

Navigate to the project directory:

cd Netflix-Data-Analysis-Capstone

Install the required libraries:

pip install -r requirements.txt

Launch Jupyter Notebook:

jupyter notebook

Open "project.ipynb" and run the notebook cells in sequence.
